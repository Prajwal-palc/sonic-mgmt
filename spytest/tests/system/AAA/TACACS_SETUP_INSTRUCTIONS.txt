OPTION 2: MANUAL SETUP
────────────────────────────────────────────────────────────────────────────────

SSH to 192.168.100.175 and run these commands:

# Install TACACS+
sudo apt update
sudo apt install -y tacacs+

# Create configuration file
sudo tee /etc/tacacs+/tac_plus.conf > /dev/null << 'EOF'
key = spytest_secret123
accounting file = /var/log/tac_plus.acct

user = tacacsadmin {
    login = cleartext adminpass123
    default service = permit
    service = exec {
        priv-lvl = 15
        shell:roles = "admin"
    }
}

user = tacacstest {
    login = cleartext testpass123
    default service = permit
    service = exec {
        priv-lvl = 15
        shell:roles = "admin"
    }
}

user = tacacsreadonly {
    login = cleartext readonly123
    default service = permit
    service = exec {
        priv-lvl = 1
        shell:roles = "operator"
    }
}
EOF

# Set permissions and restart
sudo chmod 600 /etc/tacacs+/tac_plus.conf
sudo systemctl restart tacacs_plus
sudo systemctl enable tacacs_plus
sudo systemctl status tacacs_plus

TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────────

Issue: Service won't start
Solution: Check logs
  sudo journalctl -u tacacs_plus -n 50
  sudo tail -f /var/log/syslog | grep tac_plus

Issue: Port 49 not accessible
Solution: Check firewall
  sudo ufw allow 49/tcp
  sudo iptables -L -n | grep 49

Issue: Authentication fails
Solution: Enable debug logging in /etc/tacacs+/tac_plus.conf:
  Add: accounting file = /var/log/tac_plus.acct
  Restart service and check logs
