# BGP Test ID 4.1.1: AS-PATH Loop Prevention

## Overview
- **Test ID**: 4.1.1
- **Title**: AS-PATH loop prevention
- **Topology**: `./testbeds/testbed_vs_2node.yaml`
- **Objective**: Verify AS-PATH prevents routing loops in eBGP by rejecting routes that contain the local AS in the AS_PATH attribute.

## Description
This suite expands the AS-PATH loop prevention test into multiple automatable subtests. It covers basic loop detection, AS-PATH prepend behavior, confederation and AS-override interactions, IPv6 variants, logging/diagnostics, policy-based acceptance/rejection, and negative tests.

Replace placeholder IPs/ASNs and add more peers if your `./testbeds/testbed_vs_2node.yaml` does not include multiple AS peers (some subtests are marked LAB/MANUAL when extra equipment is required).

## Test 4.1.1.1: Basic AS-PATH loop detection (direct eBGP)

### Objective
Verify a route learned via eBGP that contains the local AS in its AS_PATH is rejected and not installed in RIB/FIB.

### Preconditions
- Two routers D1 (AS 65001) and D2 (AS 65002) connected; one additional external neighbor able to advertise test prefixes (or simulate on D2).
- BGP sessions Established.

### Test Steps
1. From an external injector/peer reachable to D2, advertise prefix 198.51.200.0/24 with AS_PATH that includes 65001 (the AS of D1) — e.g., AS_PATH: 65001 65100.
2. On D1, poll `show ip bgp 198.51.200.0/24` and `show ip route 198.51.200.0/24`.

### Configuration Example (klish)

```bash
# On D2 (AS 65002) - Configure to advertise prefix with manipulated AS_PATH
configure terminal
router bgp 65002
  neighbor <D1_IP> remote-as 65001
  address-family ipv4 unicast
    neighbor <D1_IP> activate
    neighbor <D1_IP> route-map SET_ASPATH out
  exit-address-family
exit

# Configure route-map to prepend AS 65001 to AS_PATH
route-map SET_ASPATH permit 10
  match ip address prefix-list TEST_PREFIX
  set as-path prepend 65001 65100
exit

ip prefix-list TEST_PREFIX seq 10 permit 198.51.200.0/24
```

### Verification Commands

```bash
# On D1 - Verify route is NOT accepted
show ip bgp 198.51.200.0/24
show ip route 198.51.200.0/24
show ip bgp neighbors <D2_IP> received-routes
show logging | grep -i "loop"
```

### Expected Results
- `show ip bgp <prefix>` should NOT show a valid path that would cause loop; route should be absent or marked as rejected.
- `show ip route <prefix>` should NOT have FIB entry via that route.
- Check logs for messages indicating AS-PATH loop prevention (e.g., 'AS loop detected' or TCP/BGP event).
- Route containing local AS in AS_PATH is not accepted/installed on D1 — loop prevented.

### Timeout
60 seconds

### Cleanup
- Withdraw test advertisement from external injector.

### Notes
- If testbed lacks external injectors, simulate by configuring route with AS_PATH (where platform supports test injection) or mark as lab.

## Test 4.1.1.2: AS-PATH prepend does not bypass loop detection (safety)

### Objective
Verify that AS-PATH prepending on a path does not enable loops — routes containing local AS anywhere in AS_PATH must be rejected.

### Preconditions
- External peer can advertise prefixes with a prepended AS sequence (e.g., 65001 65001 65100).

### Test Steps
1. From an external peer via D2, advertise prefix with AS_PATH containing repeated local AS (65001 prepended).
2. Check `show ip bgp <prefix>` and RIB on D1.

### Configuration Example (klish)

```bash
# On D2 - Configure route-map with multiple AS prepends
route-map SET_ASPATH_PREPEND permit 10
  match ip address prefix-list TEST_PREFIX
  set as-path prepend 65001 65001 65100
exit
```

### Verification Commands

```bash
# On D1 - Verify route is still rejected despite prepending
show ip bgp 198.51.200.0/24
show ip route 198.51.200.0/24
show ip bgp neighbors <D2_IP> received-routes
```

### Expected Results
- Route should still be rejected/filtered due to occurrence of local AS in AS_PATH even if prepended multiple times.
- Prepended AS entries that include local AS must not permit loops — route rejected.

### Timeout
60 seconds

### Cleanup
- Withdraw prepended advertisement.

## Test 4.1.1.6: IPv6 AS-PATH loop prevention

### Objective
Verify AS-PATH loop prevention semantics for IPv6 NLRI are identical to IPv4 — routes containing local AS are rejected.

### Preconditions
- IPv6 BGP sessions are configured and peers can advertise IPv6 prefixes; BGPv6 supported.

### Test Steps
1. From an external peer, advertise IPv6 prefix 2001:db8:200::/64 with AS_PATH containing the local AS.
2. On this DUT, check `show ipv6 bgp <prefix>` and `show ipv6 route <prefix>`.

### Configuration Example (klish)

```bash
# On D2 - Configure IPv6 BGP with AS_PATH manipulation
configure terminal
router bgp 65002
  neighbor <D1_IPv6> remote-as 65001
  address-family ipv6 unicast
    neighbor <D1_IPv6> activate
    neighbor <D1_IPv6> route-map SET_ASPATH_v6 out
  exit-address-family
exit

route-map SET_ASPATH_v6 permit 10
  match ipv6 address prefix-list TEST_PREFIX_v6
  set as-path prepend 65001 65100
exit

ipv6 prefix-list TEST_PREFIX_v6 seq 10 permit 2001:db8:200::/64
```

### Verification Commands

```bash
# On D1 - Verify IPv6 route is NOT accepted
show ipv6 bgp 2001:db8:200::/64
show ipv6 route 2001:db8:200::/64
show ipv6 bgp neighbors <D2_IPv6> received-routes
show logging | grep -i "loop"
```

### Expected Results
- Route should not be accepted/installed; logs should indicate AS loop prevention for IPv6.
- IPv6 routes containing local AS in AS_PATH are rejected — loop prevented.

### Timeout
60 seconds

### Cleanup
- Withdraw IPv6 advertisement.

## Test 4.1.1.7: Policy bypass / manual override — ensure explicit route-map cannot create AS loop silently

### Objective
Test that administrative policies (route-maps/filters) cannot silently install a route whose AS_PATH contains the local AS, unless the platform explicitly supports and documents such behavior.

### Preconditions
- Ability to apply route-maps/policies and to control advertisements.

### Test Steps
1. On receiving router, create a route-map that would accept the route even if AS_PATH contains local AS (if platform allows).
2. Try to accept/install the prefix via the route-map.
3. Observe whether the platform blocks the policy or warns/logs about potential loop creation.

### Configuration Example (klish)

```bash
# On D1 - Configure route-map attempting to bypass loop detection
configure terminal
router bgp 65001
  neighbor <D2_IP> remote-as 65002
  address-family ipv4 unicast
    neighbor <D2_IP> route-map ACCEPT_ALL in
  exit-address-family
exit

route-map ACCEPT_ALL permit 10
exit
```

### Verification Commands

```bash
# Verify platform safety mechanisms
show ip bgp 198.51.200.0/24
show ip route 198.51.200.0/24
show logging | grep -i "loop\|warn\|error"
show ip bgp neighbors <D2_IP> routes
```

### Expected Results
- Platform either prevents installation, logs a warning, or requires an additional explicit knob to allow such risky config. It must not silently create an AS loop in forwarding plane.
- Safe-guarding behavior: either policy is refused, documented warning emitted, or operator must explicitly enable dangerous behavior.

### Timeout
60 seconds

### Cleanup
- Remove test route-map/policy.

### Notes
- This test checks platform safety; behavior may be vendor-specific — document findings.

## Test 4.1.1.8: Logging, diagnostics and packet-capture for AS loop events

### Objective
Collect and validate logs/pcap evidence when AS-PATH loop prevention triggers — ensure diagnostic information is sufficient for operators.

### Preconditions
- Access to /var/log/frr/frr.log (or vendor logs) and ability to run packet capture on relevant interface.

### Test Steps
1. Start tcpdump on the DUT interface receiving the suspicious advertisement: `tcpdump -w /tmp/aspath_loop.pcap -i <if> port 179`.
2. Trigger a test advertisement that contains the local AS in AS_PATH (as in 4.1.1.1).
3. Collect BGP and system logs around event time and save pcap and logs.

### Configuration Example

```bash
# Start packet capture
sudo tcpdump -w /tmp/aspath_loop.pcap -i Ethernet0 port 179 &

# Trigger test via BGP configuration (as in 4.1.1.1)
```

### Verification Commands

```bash
# Collect diagnostic information
show logging | grep -i "bgp\|loop\|as.path"
cat /var/log/frr/frr.log | grep -i "loop"
ls -la /tmp/aspath_loop.pcap

# Analyze pcap (if tcpdump available)
tcpdump -r /tmp/aspath_loop.pcap -vv port 179
```

### Expected Results
- Logs show a clear AS loop detection message or BGP update rejection reason.
- PCAP contains the UPDATE messages with AS_PATH attribute showing local AS occurrence.
- Sufficient evidence in logs+pcap to diagnose AS loop prevention event.

### Timeout
120 seconds

### Cleanup
- Stop tcpdump and remove pcap if not needed.
