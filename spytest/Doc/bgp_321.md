# BGP Test ID 3.2.1 - IPv4 Route Advertisement

## Overview

**Test ID:** 3.2.1
**Test Category:** BGP IPv4 Route Advertisement
**Topology:** testbeds/testbed_vs_2node.yaml
**CLI Type:** klish

This test suite validates IPv4 unicast route advertisement functionality in BGP, covering various scenarios including:
- Basic network advertisement via `network` command
- Multiple prefix advertisement
- Route redistribution (connected and static routes)
- iBGP and eBGP scenarios
- BGP attribute manipulation (MED, Local Preference, AS-PATH, Communities)
- Route filtering (prefix-lists and route-maps)
- Route aggregation
- Dynamic route withdrawal
- IPv6 basic advertisement
- Maximum prefix limits
- Route refresh capability

## Test Case 3.2.1.1: Basic IPv4 Network Advertisement via network command

### Description
Verify basic IPv4 network advertisement from R1 (D1) to R2 (D2) using the BGP `network` command.

### Topology
- **Connection:** D1-Ethernet4 (10.0.0.1/30) <---> D2-Ethernet4 (10.0.0.2/30)
- **BGP Session:** eBGP between AS 65001 and AS 65002
- **Advertised Network:** 192.168.1.0/24 (D1 Loopback1)

### Configuration

#### D1 (Router 1) Configuration

```bash
# Enter configuration mode
sonic# configure terminal

# Configure Ethernet4 interface
sonic(config)# interface Ethernet4
sonic(conf-if-Ethernet4)# ip address 10.0.0.1/30
sonic(conf-if-Ethernet4)# no shutdown
sonic(conf-if-Ethernet4)# exit

# Configure Loopback1 interface
sonic(config)# interface Loopback1
sonic(conf-if-Loopback1)# ip address 192.168.1.1/24
sonic(conf-if-Loopback1)# exit

# Configure BGP
sonic(config)# router bgp 65001
sonic(config-router-bgp)# router-id 1.1.1.1
sonic(config-router-bgp)# neighbor 10.0.0.2 remote-as 65002
sonic(config-router-bgp)# address-family ipv4 unicast
sonic(config-router-bgp-af)# network 192.168.1.0/24
sonic(config-router-bgp-af)# neighbor 10.0.0.2 activate
sonic(config-router-bgp-af)# exit
sonic(config-router-bgp)# exit
```

#### D2 (Router 2) Configuration

```bash
# Enter configuration mode
sonic# configure terminal

# Configure Ethernet4 interface
sonic(config)# interface Ethernet4
sonic(conf-if-Ethernet4)# ip address 10.0.0.2/30
sonic(conf-if-Ethernet4)# no shutdown
sonic(conf-if-Ethernet4)# exit

# Configure BGP
sonic(config)# router bgp 65002
sonic(config-router-bgp)# router-id 2.2.2.2
sonic(config-router-bgp)# neighbor 10.0.0.1 remote-as 65001
sonic(config-router-bgp)# address-family ipv4 unicast
sonic(config-router-bgp-af)# neighbor 10.0.0.1 activate
sonic(config-router-bgp-af)# exit
sonic(config-router-bgp)# exit
```

### Verification

#### Verify BGP Session Establishment

**On D1:**
```bash

```

**On D2:**
```bash
sonic# show bgp ipv4 unicast summary

Neighbor        V    AS MsgRcvd MsgSent   TblVer  InQ OutQ  Up/Down State/PfxRcd
10.0.0.1        4 65001       6       5        0    0    0 00:01:23            1
```

#### Verify Route Advertisement

**On D2 - Check if 192.168.1.0/24 is received:**

## Test Case 3.2.1.13: IPv4 Advertisement with Route-Map Filtering

### Description
Verify selective IPv4 route advertisement using route-map with match conditions.

### Configuration

#### D1 Configuration

```bash
sonic# configure terminal

# Configure loopback interfaces
sonic(config)# interface Loopback1
sonic(conf-if-Loopback1)# ip address 172.16.1.1/24
sonic(conf-if-Loopback1)# exit

sonic(config)# interface Loopback2
sonic(conf-if-Loopback2)# ip address 172.16.2.1/24
sonic(conf-if-Loopback2)# exit

sonic(config)# interface Loopback3
sonic(conf-if-Loopback3)# ip address 172.16.3.1/24
sonic(conf-if-Loopback3)# exit

# Create prefix-list for matching
sonic(config)# ip prefix-list MATCH_172_16_1 seq 10 permit 172.16.1.0/24

# Create route-map that permits only 172.16.1.0/24
sonic(config)# route-map FILTER_ROUTES permit 10
sonic(config-route-map)# match ip address prefix-list MATCH_172_16_1
sonic(config-route-map)# exit
sonic(config)# route-map FILTER_ROUTES deny 20
sonic(config-route-map)# exit

# Apply route-map to BGP
sonic(config)# router bgp 65001
sonic(config-router-bgp)# address-family ipv4 unicast
sonic(config-router-bgp-af)# network 172.16.1.0/24
sonic(config-router-bgp-af)# network 172.16.2.0/24
sonic(config-router-bgp-af)# network 172.16.3.0/24
sonic(config-router-bgp-af)# neighbor 10.0.0.2 route-map FILTER_ROUTES out
sonic(config-router-bgp-af)# exit
```

### Verification

**On D2:**
