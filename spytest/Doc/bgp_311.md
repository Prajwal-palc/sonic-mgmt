## Test Case 3.1.1.1: Basic LOCAL_PREF preference (two iBGP peers)

### Objective
Advertise identical prefix from two external peers into the AS; set LOCAL_PREF differing values on import and verify best path selection.

### Preconditions
- Two external peers (or test injectors) advertise same IPv4 prefix to two iBGP border routers (or D1/D2 configured to simulate).
- iBGP sessions Established and route propagation functioning.

### Test Steps
1. On ingress neighbor A -> D1, advertise prefix 198.51.100.0/24.
2. On ingress neighbor B -> D2, advertise same prefix 198.51.100.0/24.
3. On D1: set route-map/policy for neighbor A to set LOCAL_PREF = 200 on imported route.
4. On D2: set route-map/policy for neighbor B to set LOCAL_PREF = 100 on import.
5. On an internal router (or same D1/D2), run `show ip bgp 198.51.100.0/24` and `show bgp summary`

#### CLI Example (D1 Configuration)
```
router bgp 65001
  neighbor <A-ip> route-map SET_LOCAL_PREF_IN in
route-map SET_LOCAL_PREF_IN permit 10
  set local-preference 200
```

### Verification
- `show ip bgp 198.51.100.0/24 -j` should show the best path with LOCAL_PREF 200 selected.
- `show ip bgp` bestpath indicates preference toward the route learned via D1 (LOCAL_PREF=200).

### Expected Results
- Route with LOCAL_PREF=200 is chosen as best-path across the AS.

### Timeout
60 seconds

### Cleanup
- Remove route-map/policy changes and withdraw test advertisements.

### Objective

### Preconditions

### Test Steps

3. On internal router, verify best path selection favors shorter AS-PATH; if AS-PATH equal, prefer lower IGP metric (adjust IGP cost on one path to test).

### Verification
- show ip bgp <prefix> shows chosen path has shorter AS-PATH or lower IGP metric per tie-break rules.

### Expected Results
- LOCAL_PREF equal -> shortest AS-PATH selected -> if tie, lowest IGP metric selected.

90 seconds

### Objective

### Preconditions

### Test Steps
1. Reduce LOCAL_PREF on path A from 300 to 50 (via policy update).
2. Record timestamp t0 when change applied.
3. Poll `show ip bgp <prefix>` until new best-path selected; record t1.

### Verification
- Best-path switches to path B within acceptable time (policy defined threshold e.g., < 30s).

### Expected Results
- Best-path updates promptly when LOCAL_PREF modified; measured convergence within acceptable window.
