# BGP Test ID 3.2.2: IPv6 Unicast Route Advertisement

## Test Overview

**Test ID**: 3.2.2
**Test Category**: BGP IPv6 Unicast Route Advertisement
**Topology**: testbed_vs_2node.yaml (2 DUTs, 1 link)
**CLI Type**: klish (BGP configuration requires klish/vtysh mode)
**Test Objective**: Verify IPv6 unicast routes are advertised correctly in various BGP scenarios

## Test Coverage

This test suite covers 8 sub-testcases validating IPv6 route advertisement:

- **3.2.2.1**: Basic IPv6 Network Advertisement via eBGP (Single Prefix)
- **3.2.2.2**: Multiple IPv6 Network Advertisements via eBGP
- **3.2.2.3**: IPv6 Network Advertisement via iBGP (Single Prefix)
- **3.2.2.4**: IPv6 Network Advertisement via iBGP (Multiple Prefixes)
- **3.2.2.5**: IPv6 Network Advertisement with Next-Hop-Self (iBGP)
- **3.2.2.6**: IPv6 Network Advertisement from Loopback Addresses
- **3.2.2.7**: IPv6 Network Advertisement with Prefix-List Filtering
- **3.2.2.8**: IPv6 Network Advertisement with Bidirectional Exchange

## Test Case 3.2.2.1: Basic IPv6 Network Advertisement via eBGP (Single Prefix)

### Test Objective
Verify a single IPv6 network is advertised correctly from D1 to D2 via eBGP.

### Topology
```
[D1] AS 65001                      [D2] AS 65002
  Lo1: 2001:db8:100::1/128
  Eth4: 2001:db8:24::1/64 <-------> Eth4: 2001:db8:24::2/64
```

### Configuration Steps

#### D1 Configuration
```
# Configure interface
sonic(config)# interface Ethernet 4
sonic(conf-if-Ethernet4)# ipv6 address 2001:db8:24::1/64
sonic(conf-if-Ethernet4)# no shutdown
sonic(conf-if-Ethernet4)# exit

# Configure loopback
sonic(config)# interface Loopback 1
sonic(conf-if-Loopback1)# ipv6 address 2001:db8:100::1/128
sonic(conf-if-Loopback1)# exit

# Configure BGP
sonic(config)# router bgp 65001
sonic(config-router-bgp)# router-id 1.1.1.1
sonic(config-router-bgp)# neighbor 2001:db8:24::2 remote-as 65002
sonic(config-router-bgp)# address-family ipv6 unicast
sonic(config-router-bgp-af)# neighbor 2001:db8:24::2 activate
sonic(config-router-bgp-af)# network 2001:db8:100::1/128
sonic(config-router-bgp-af)# exit
sonic(config-router-bgp)# exit
```

#### D2 Configuration
```
# Configure interface
sonic(config)# interface Ethernet 4
sonic(conf-if-Ethernet4)# ipv6 address 2001:db8:24::2/64
sonic(conf-if-Ethernet4)# no shutdown
sonic(conf-if-Ethernet4)# exit

# Configure BGP
sonic(config)# router bgp 65002
sonic(config-router-bgp)# router-id 2.2.2.2
sonic(config-router-bgp)# neighbor 2001:db8:24::1 remote-as 65001
sonic(config-router-bgp)# address-family ipv6 unicast
sonic(config-router-bgp-af)# neighbor 2001:db8:24::1 activate
sonic(config-router-bgp-af)# exit
sonic(config-router-bgp)# exit
```

## Test Case 3.2.2.5: IPv6 Network Advertisement with Next-Hop-Self (iBGP)

### Test Objective
Verify IPv6 routes advertised with next-hop-self in iBGP scenario over loopback-based peering.

### Topology
```
[D1] AS 65001                      [D2] AS 65001
  Lo0: 2001:db8:1::1/128            Lo0: 2001:db8:2::2/128
  Lo1: 2001:db8:100::1/128
  Eth4: 2001:db8:24::1/64 <-------> Eth4: 2001:db8:24::2/64

  BGP peering: 2001:db8:1::1 <----> 2001:db8:2::2 (over loopbacks)
```

### Configuration Steps

#### D1 Configuration
```
# Configure interface
sonic(config)# interface Ethernet 4
sonic(conf-if-Ethernet4)# ipv6 address 2001:db8:24::1/64
sonic(conf-if-Ethernet4)# no shutdown
sonic(conf-if-Ethernet4)# exit

# Configure loopbacks
sonic(config)# interface Loopback 0
sonic(conf-if-Loopback0)# ipv6 address 2001:db8:1::1/128
sonic(conf-if-Loopback0)# exit

sonic(config)# interface Loopback 1
sonic(conf-if-Loopback1)# ipv6 address 2001:db8:100::1/128
sonic(conf-if-Loopback1)# exit

# Configure static route for BGP peering
sonic(config)# ipv6 route 2001:db8:2::2/128 2001:db8:24::2

# Configure BGP
sonic(config)# router bgp 65001
sonic(config-router-bgp)# router-id 1.1.1.1
sonic(config-router-bgp)# neighbor 2001:db8:2::2 remote-as 65001
sonic(config-router-bgp)# neighbor 2001:db8:2::2 update-source Loopback0
sonic(config-router-bgp)# address-family ipv6 unicast
sonic(config-router-bgp-af)# neighbor 2001:db8:2::2 activate
sonic(config-router-bgp-af)# neighbor 2001:db8:2::2 next-hop-self
sonic(config-router-bgp-af)# network 2001:db8:100::1/128
sonic(config-router-bgp-af)# exit
sonic(config-router-bgp)# exit
```

#### D2 Configuration

## Troubleshooting

### BGP Session Not Establishing
1. Verify IPv6 connectivity: `ping6 <neighbor-ipv6>`
2. Check BGP neighbor configuration: `show running-config | grep bgp`
3. Verify interface status: `show ipv6 interface brief`
4. Check BGP neighbor state: `show bgp ipv6 neighbors <neighbor-ip>`

### Routes Not Being Advertised
1. Verify network statement: `show running-config | section bgp`
2. Check prefix-list (if configured): `show ipv6 prefix-list <name>`
3. Verify address-family activation: `show bgp ipv6 neighbors <neighbor-ip>`
4. Check soft-reconfiguration: Clear BGP session with `clear bgp ipv6 <neighbor-ip> soft`

### Next-Hop Issues
1. Verify next-hop reachability: `ping6 <next-hop-ipv6>`
2. Check next-hop-self configuration (for iBGP)
3. Verify static routes (for loopback-based peering)
4. Check update-source configuration

### Prefix-List Not Filtering
1. Verify prefix-list syntax: `show ipv6 prefix-list <name>`
2. Check prefix-list application: `show running-config | section neighbor`
3. Clear BGP session to apply changes: `clear bgp ipv6 <neighbor-ip>`

## Notes and Considerations

1. **IPv6 Address Format**: Use full or compressed IPv6 address format consistently
2. **BGP Timers**: Default keepalive (60s) and hold (180s) timers used unless specified
3. **Route Advertisement**: Network statement must match exact prefix and prefix-length
4. **Next-Hop Behavior**:
   - eBGP: Next-hop is the advertising router's interface IP
   - iBGP: Next-hop is preserved unless next-hop-self is configured
5. **Multi-hop**: Required for loopback-based eBGP peering
6. **Prefix-List Ordering**: Rules are evaluated sequentially; explicit deny-all needed at end
7. **Address Family Activation**: Must explicitly activate neighbors under IPv6 unicast address-family
